# Copies locales et tables intermédiaires

Ce dossier contient les copies locales des sources téléchargées et les tables intermédiaires de la chaîne. Tout son contenu est ignoré par git, sauf ce fichier, parce que ces fichiers sont gros et qu'on peut les recréer.

Les copies datées des sources sont conservées dans des releases GitHub (décision ADR-DATA-A, écrite par EDU-8). Les tables intermédiaires vont dans `data/brut/intermediaire/`.
